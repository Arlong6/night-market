# 橫衝直撞 (Road Rage) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the v1 vertical slice of a top-down 2D vehicle-destruction sandbox — drive a heavy car, smash a procedurally-populated city, build combos, escalate a wanted level with chasing police, chase a high score — with a full juice pass.

**Architecture:** A new standalone Godot 4.6 project at `road-rage/`. Pure-logic units (impact math, wanted, combo, score, city generation, audio synthesis) are `RefCounted`/static classes that are fully unit-tested with GUT. Node scripts (Vehicle, Destructible, Police, CameraRig, Main, Title) compose those units and are verified by headless boot + user playtest. All art and audio are generated in code (zero asset dependency).

**Tech Stack:** Godot 4.6, GDScript (static typing), 2D top-down, GL Compatibility renderer, GUT 9.x for tests, procedural AudioStreamWAV audio, programmatic `_draw()` art.

## Global Constraints

- Engine: Godot 4.6 (binary at `~/Downloads/godot-4.6.2/Godot.app/Contents/MacOS/Godot`). Verify APIs against `docs/engine-reference/godot/` before using post-4.3 calls.
- Language: GDScript with static typing on all vars/params/returns where practical.
- Renderer: `gl_compatibility` (Web target). Keep total download small; no bundled binary art.
- Audio: never play on `_ready` or a loop at boot — first sound only after a user gesture (the title click), per Web autoplay rules.
- Naming: classes PascalCase, files snake_case, vars snake_case, signals snake_case past-tense, constants UPPER_SNAKE.
- CJK HUD text needs the bundled font (`ThemeDB.fallback_font` has no CJK on Web).
- Tests: GUT. Run a single file with `"$GODOT" --headless -s addons/gut/gut_cmdln.gd -gtest=res://tests/unit/<file>.gd -gexit` from `road-rage/`. Run all unit tests with `-gdir=res://tests/unit -ginclude_subdirs`. After adding a new `class_name`, refresh the class cache once: `"$GODOT" --headless --editor --quit`.
- `GODOT` shell var used throughout: `GODOT=~/Downloads/godot-4.6.2/Godot.app/Contents/MacOS/Godot`

static func impact_force(speed: float, mass: float) -> float:
	return absf(speed) * mass

## Does an impact of `force` break an object whose break threshold is `threshold`?
static func breaks_at(force: float, threshold: float) -> bool:

```gdscript
## Vehicle — top-down arcade car for 橫衝直撞. Heavy momentum + steering.
class_name Vehicle
extends CharacterBody2D

signal died

var hp: float = RRTuning.VEHICLE_HP
const MASS: float = RRTuning.VEHICLE_MASS

var _w: float = 22.0
var _h: float = 12.0

func _ready() -> void:
	var col := CollisionShape2D.new()
	var rect := RectangleShape2D.new()
	rect.size = Vector2(_w * 2.0, _h * 2.0)
	col.shape = rect
	add_child(col)
	motion_mode = CharacterBody2D.MOTION_MODE_FLOATING

func speed() -> float:
	return velocity.length()

func _physics_process(delta: float) -> void:
	var throttle: float = Input.get_axis("brake", "accel")
	var steer: float = Input.get_axis("left", "right")
	# Steering scales with how fast you're going (no pivot-in-place).
	var speed_frac: float = clampf(speed() / RRTuning.MAX_SPEED, 0.0, 1.0)
	rotation += steer * RRTuning.TURN_RATE * delta * (0.35 + 0.65 * speed_frac)
	var forward: Vector2 = Vector2.RIGHT.rotated(rotation)
	if throttle > 0.0:
		velocity += forward * RRTuning.ACCEL * delta
	elif throttle < 0.0:
		velocity -= forward * RRTuning.ACCEL * delta
	# Passive friction
	var fr: float = RRTuning.FRICTION * delta
	if velocity.length() <= fr:
		velocity = Vector2.ZERO
	else:
		velocity -= velocity.normalized() * fr
	velocity = velocity.limit_length(RRTuning.MAX_SPEED)
	move_and_slide()

func bleed_speed(factor: float) -> void:
	velocity *= factor

func take_damage(d: float) -> void:
	hp = maxf(0.0, hp - d)
	if hp <= 0.0:
		died.emit()

func _draw() -> void:
	# Body
	draw_rect(Rect2(-_w, -_h, _w * 2.0, _h * 2.0), Color("#D24B2A"))
	# Windshield (front = +x)
	draw_rect(Rect2(_w * 0.2, -_h * 0.7, _w * 0.5, _h * 1.4), Color("#2A2E38"))
	# Nose marker
	draw_rect(Rect2(_w - 3.0, -2.0, 3.0, 4.0), Color("#FFE08A"))
```

## CameraRig — follows a target with trauma-based shake + zoom punch.
class_name CameraRig
extends Camera2D

var _target: Node2D = null
var _trauma: float = 0.0
var _base_zoom: Vector2 = Vector2.ONE
var _zoom_kick: float = 0.0

func setup(target: Node2D) -> void:
	_target = target
	make_current()

func shake(strength: float) -> void:
	_trauma = minf(1.0, _trauma + strength)

func punch(amount: float) -> void:
	_zoom_kick = maxf(_zoom_kick, amount)

func _process(delta: float) -> void:
	if _target and is_instance_valid(_target):
		global_position = global_position.lerp(_target.global_position, 1.0 - pow(0.001, delta))
	_trauma = maxf(0.0, _trauma - delta * 1.5)
	var amt: float = _trauma * _trauma
	offset = Vector2(randf_range(-1.0, 1.0), randf_range(-1.0, 1.0)) * 12.0 * amt
	_zoom_kick = maxf(0.0, _zoom_kick - delta * 4.0)
	zoom = _base_zoom * (1.0 + _zoom_kick)
```

## FX — one-shot particle bursts + physics debris chunks (橫衝直撞).
class_name FX
extends RefCounted

static func burst(parent: Node, pos: Vector2, color: Color, count: int = 16) -> void:
	if parent == null or not is_instance_valid(parent):
		return
	var p := CPUParticles2D.new()
	p.position = pos
	p.amount = count
	p.lifetime = 0.5
	p.one_shot = true
	p.explosiveness = 0.95
	p.spread = 180.0
	p.initial_velocity_min = 70.0
	p.initial_velocity_max = 220.0
	p.scale_amount_min = 1.5
	p.scale_amount_max = 3.5
	p.color = color
	p.emitting = true
	parent.add_child(p)
	parent.get_tree().create_timer(0.9).timeout.connect(func() -> void:
		if is_instance_valid(p): p.queue_free())

static func debris(parent: Node, pos: Vector2, color: Color, chunks: int = 5) -> void:
	if parent == null or not is_instance_valid(parent):
		return
	for i in chunks:
		var r := RigidBody2D.new()
		r.position = pos
		r.gravity_scale = 0.0
		r.linear_damp = 2.5
		var col := CollisionShape2D.new()
		var shape := CircleShape2D.new()
		shape.radius = 3.0
		col.shape = shape
		col.disabled = true   # debris is purely visual
		r.add_child(col)
		var poly := Polygon2D.new()
		var s: float = randf_range(2.0, 5.0)
		poly.polygon = PackedVector2Array([Vector2(-s,-s), Vector2(s,-s), Vector2(s,s), Vector2(-s,s)])
		poly.color = color
		r.add_child(poly)
		parent.add_child(r)
		r.linear_velocity = Vector2.RIGHT.rotated(randf_range(0.0, TAU)) * randf_range(120.0, 320.0)
		r.angular_velocity = randf_range(-12.0, 12.0)
		var t := r.create_tween()
		t.tween_interval(0.4)
		t.tween_property(r, "modulate:a", 0.0, 0.5)
		t.tween_callback(func() -> void:
			if is_instance_valid(r): r.queue_free())
```

## Destructible — a world object that breaks when the car hits it hard enough.
class_name Destructible
extends Area2D

signal destroyed(kind: String, value: int, heat: int, pos: Vector2)

@export var kind: String = "prop"
var broke: bool = false

const _THRESHOLD := {
	"prop": RRTuning.BREAK_THRESHOLD_PROP,
	"car": RRTuning.BREAK_THRESHOLD_CAR,
	"ped": RRTuning.BREAK_THRESHOLD_PED,
}
const _SCORE := {"prop": RRTuning.SCORE_PROP, "car": RRTuning.SCORE_CAR, "ped": RRTuning.SCORE_PED}
const _HEAT := {"prop": RRTuning.HEAT_PROP, "car": RRTuning.HEAT_CAR, "ped": RRTuning.HEAT_PED}
const _COLOR := {"prop": Color("#C8A24A"), "car": Color("#4A7AC8"), "ped": Color("#E0B0A0")}
const _SIZE := {"prop": 14.0, "car": 20.0, "ped": 8.0}

func _ready() -> void:
	var col := CollisionShape2D.new()
	var shape := CircleShape2D.new()
	shape.radius = _SIZE.get(kind, 14.0)
	col.shape = shape
	add_child(col)
	body_entered.connect(_on_body_entered)
	queue_redraw()

func _on_body_entered(body: Node) -> void:
	if broke or not body is Vehicle:
		return
	var v: Vehicle = body
	var force: float = RRPhysics.impact_force(v.speed(), Vehicle.MASS)
	if RRPhysics.breaks_at(force, _THRESHOLD.get(kind, 9999.0)):
		_break(v)

func _break(v: Vehicle) -> void:
	broke = true
	var c: Color = _COLOR.get(kind, Color.WHITE)
	FX.burst(get_parent(), global_position, c, 14 if kind != "car" else 24)
	FX.debris(get_parent(), global_position, c, 5 if kind != "car" else 9)
	v.bleed_speed(RRTuning.SPEED_BLEED_ON_BREAK if kind != "car" else 0.55)
	destroyed.emit(kind, _SCORE.get(kind, 10), _HEAT.get(kind, 8), global_position)
	queue_free()

func _draw() -> void:
	var s: float = _SIZE.get(kind, 14.0)
	draw_rect(Rect2(-s, -s, s * 2.0, s * 2.0), _COLOR.get(kind, Color.WHITE))
```

## RRAudio — procedural SFX for 橫衝直撞 (impact crunch, explosion, siren).
## Web-safe: only ever played from a user-caused event.
class_name RRAudio
extends RefCounted

const SAMPLE_RATE: int = 22050
static var _impact: AudioStreamWAV = null
static var _explosion: AudioStreamWAV = null
static var _siren: AudioStreamWAV = null

static func impact(parent: Node, force: float) -> void:
	if _impact == null: _impact = _make_impact()
	var db: float = lerpf(-14.0, -2.0, clampf(force / 1500.0, 0.0, 1.0))
	_play(parent, _impact, db)

static func explosion(parent: Node) -> void:
	if _explosion == null: _explosion = _make_explosion()
	_play(parent, _explosion, -3.0)

static func siren(parent: Node) -> void:
	if _siren == null: _siren = _make_siren()
	_play(parent, _siren, -10.0)

static func _play(parent: Node, stream: AudioStream, db: float) -> void:
	if parent == null or stream == null or not is_instance_valid(parent): return
	var p := AudioStreamPlayer.new()
	p.stream = stream
	p.volume_db = db
	parent.add_child(p)
	p.play()
	p.finished.connect(p.queue_free)

# Crunchy noise burst with a low thump.
static func _make_impact() -> AudioStreamWAV:
	var dur := 0.18
	var n := int(SAMPLE_RATE * dur)
	var data := PackedByteArray(); data.resize(n * 2)
	var seed_v := 12345
	for i in n:
		var t: float = float(i) / SAMPLE_RATE
		var env: float = pow(1.0 - t / dur, 1.8)
		seed_v = (seed_v * 1103515245 + 12345) & 0x7fffffff
		var noise: float = (float(seed_v) / 1073741823.0) - 1.0
		var thump: float = sin(t * TAU * lerpf(150.0, 70.0, t / dur))
		_w(data, i, (noise * 0.5 + thump * 0.5) * env * 0.6)
	return _wrap(data)

# Longer, lower boom.
static func _make_explosion() -> AudioStreamWAV:
	var dur := 0.6
	var n := int(SAMPLE_RATE * dur)
	var data := PackedByteArray(); data.resize(n * 2)
	var seed_v := 9876
	for i in n:
		var t: float = float(i) / SAMPLE_RATE
		var env: float = pow(1.0 - t / dur, 1.3)
		seed_v = (seed_v * 1103515245 + 12345) & 0x7fffffff
		var noise: float = (float(seed_v) / 1073741823.0) - 1.0
		var boom: float = sin(t * TAU * lerpf(110.0, 40.0, t / dur))
		_w(data, i, (noise * 0.4 + boom * 0.6) * env * 0.7)
	return _wrap(data)

# Two-tone siren loop fragment.
static func _make_siren() -> AudioStreamWAV:
	var dur := 0.9
	var n := int(SAMPLE_RATE * dur)
	var data := PackedByteArray(); data.resize(n * 2)
	for i in n:
		var t: float = float(i) / SAMPLE_RATE
		var freq: float = 660.0 if fmod(t, 0.45) < 0.225 else 520.0
		_w(data, i, sin(t * TAU * freq) * 0.4)
	return _wrap(data)

static func _w(data: PackedByteArray, idx: int, s: float) -> void:
	var v: int = int(clampf(s, -1.0, 1.0) * 32767.0)
	if v < 0: v += 65536
	data[idx * 2] = v & 0xFF
	data[idx * 2 + 1] = (v >> 8) & 0xFF

static func _wrap(data: PackedByteArray) -> AudioStreamWAV:
	var st := AudioStreamWAV.new()
	st.format = AudioStreamWAV.FORMAT_16_BITS
	st.mix_rate = SAMPLE_RATE
	st.stereo = false
	st.data = data
	return st
```

```gdscript
## ComboSystem — chains destructions within a time window into a multiplier.
class_name ComboSystem
extends RefCounted

var _count: int = 0
var _timer: float = 0.0

func register(value: int) -> int:
	_count += 1
	_timer = RRTuning.COMBO_WINDOW
	return value * multiplier()

func multiplier() -> int:
	return clampi(_count, 1, RRTuning.COMBO_MAX_MULT)

func count() -> int:
	return _count

func is_active() -> bool:
	return _count > 0 and _timer > 0.0

func tick(dt: float) -> void:
	if _count == 0:
		return
	_timer -= dt
	if _timer <= 0.0:
		_count = 0
		_timer = 0.0
```

## ScoreSystem — run score + destruction count + persistent bests.
class_name ScoreSystem
extends RefCounted

const SAVE_PATH: String = "user://road_rage.cfg"
const SECTION: String = "scores"

var score: int = 0
var destroyed: int = 0

func add(points: int, count: int = 1) -> void:
	score += points
	destroyed += count

func load_best() -> int:
	var cfg := ConfigFile.new()
	if cfg.load(SAVE_PATH) != OK: return 0
	return int(cfg.get_value(SECTION, "best", 0))

func load_best_destroyed() -> int:
	var cfg := ConfigFile.new()
	if cfg.load(SAVE_PATH) != OK: return 0
	return int(cfg.get_value(SECTION, "best_destroyed", 0))

func submit() -> bool:
	var cfg := ConfigFile.new()
	cfg.load(SAVE_PATH)
	var prev: int = int(cfg.get_value(SECTION, "best", 0))
	var prev_d: int = int(cfg.get_value(SECTION, "best_destroyed", 0))
	var is_new: bool = score > prev
	if is_new: cfg.set_value(SECTION, "best", score)
	if destroyed > prev_d: cfg.set_value(SECTION, "best_destroyed", destroyed)
	cfg.save(SAVE_PATH)
	return is_new

## CityGen — deterministic district layout from a seed (橫衝直撞).
class_name CityGen
extends RefCounted

func generate(seed: int) -> Dictionary:
	var rng := RandomNumberGenerator.new()
	rng.seed = seed
	var buildings: Array[Vector2i] = []
	var props: Array[Dictionary] = []
	for y in RRTuning.CITY_ROWS:
		for x in RRTuning.CITY_COLS:
			# Every 4th row/col is a road — keep it clear for driving.
			var is_road: bool = (x % 4 == 0) or (y % 4 == 0)
			if is_road:
				continue
			if rng.randf() < RRTuning.BUILDING_CHANCE:
				buildings.append(Vector2i(x, y))
			elif rng.randf() < RRTuning.PROP_CHANCE:
				var roll: float = rng.randf()
				var kind: String = "prop" if roll < 0.7 else ("car" if roll < 0.9 else "ped")
				props.append({"cell": Vector2i(x, y), "kind": kind})
	return {"buildings": buildings, "props": props}

```gdscript
## WantedSystem — accumulates heat from destruction into a 0..5 star level.
class_name WantedSystem
extends RefCounted

var _heat: float = 0.0

func add_heat(n: int) -> void:
	_heat += float(n)

func decay(dt: float) -> void:
	_heat = maxf(0.0, _heat - RRTuning.HEAT_DECAY_PER_SEC * dt)

func heat() -> float:
	return _heat

func stars() -> int:
	var s: int = 0
	for i in RRTuning.STAR_THRESHOLDS.size():
		if _heat >= float(RRTuning.STAR_THRESHOLDS[i]):
			s = i
	return s
```

	_dmg_cooldown = maxf(0.0, _dmg_cooldown - delta)
	if target == null or not is_instance_valid(target):

	var dir: Vector2 = (target.global_position - global_position).normalized()

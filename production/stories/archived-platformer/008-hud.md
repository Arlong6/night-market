## Goal

Implement the diegetic receipt-style HUD from art-bible §3D: cream receipt
strip pinned to the top-left corner showing score, timer, and death count
in stamp-red pixel font. Updates live from the `Game` singleton signals.

## Acceptance Criteria

- [ ] HUD is a `CanvasLayer` scene at `src/scenes/hud.tscn` + `src/scripts/hud.gd`
- [ ] CanvasLayer `layer = 10` (above gameplay layer 0)
- [ ] Receipt strip: 128×24 cream (`#F5EDDA`) panel at screen position (2, 2) with 1px ink-black (`#2A1A0A`) bottom border
- [ ] Three text elements on the strip, all in stamp-red (`#C2241A`) at 10px pixel font:
  - [ ] `SCORE 0000` (zero-padded to 4 digits, left)
  - [ ] `TIME 0:00` (minutes:seconds, center)
  - [ ] `✗ 0` or `D 0` (death count with simple symbol, right)
- [ ] Text elements use a bitmap font (BMFont `.fnt` + `.png`) — NOT TTF
  - [ ] If no pixel font asset exists yet: ship a Godot default pixel font (e.g., the editor's own mono) as a placeholder and flag it for replacement in Story 011 or post-MVP
  - [ ] Font file path documented in `.claude/docs/technical-preferences.md` Allowed Libraries
- [ ] Connects to `Game.score_changed` and `Game.deaths_changed` signals — updates labels live
- [ ] Connects to `Game.session_time` via `_process` polling each frame (or separate timer signal — polling is fine for MVP since time is always changing)
- [ ] Text is anchor-positioned so the receipt strip sticks to top-left regardless of window scale (1280×720 browser window → 320×180 internal, Control node layout handles this via anchors)
- [ ] HUD is visible during gameplay but HIDDEN during menus (Story 010 toggles via signal)

## Implementation Notes

- Use `Control` nodes (`Label`, `ColorRect`) for text and strip background. Follow Godot 4 UI Control anchor workflow.
- Art-bible §8L TRAP: do not mix Control and Node2D in same layer. HUD lives in its own CanvasLayer, separate from gameplay.
- `texture_filter = TEXTURE_FILTER_NEAREST` must be set on the HUD's root Control AND inherited by all children (or set per-node). Otherwise Godot's default bilinear will blur the pixel font even with project-wide setting.
- Time format: `"%d:%02d" % [floor(t/60), int(t) % 60]`
- Zero-padded score: `"%04d" % score`
- Visual tuning (font size, exact pixel positions) is expected to need iteration — note the first-draft layout will likely get adjusted after seeing it on screen. Document the final layout in evidence doc.

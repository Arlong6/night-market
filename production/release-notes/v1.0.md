## 🌃 夜市採購 (Night Market)

**逛市場、跟攤販討價還價、買齊媽媽交代的食材回家煮**。一場 5-10 分鐘的台味散步小遊戲。

### v1.0 五大亮點

1. **媽媽特別交代** — 每週循環不同的食材清單，遇到下雨/颱風天還會臨時加碼買傘
2. **時段流轉** — 從黃昏走到深夜，天色慢慢深，燈籠慢慢亮，攤位陸續準備收攤
3. **天氣 + 雨傘系統** — 預測得到的雨天、突發的颱風天，沒撐傘會被淋濕
4. **街頭路人 + 寵物追隨** — 街頭藝人放音樂可給 NT$2 小費，沿路救回的貓會回家跟著主角
5. **小賭一把** — 算命阿婆攤位 NT$5 賭運氣、NT$10 抽獎攤一晚最多 3 抽免費食材

### 玩法簡介

- 滑鼠左鍵走路（格子移動）
- 點攤位開始討價還價（拖拉橫桿停在綠色區）
- N 鍵打開食譜筆記
- 完成媽媽清單回家煮飯結算

## 📜 字典村莊 (Lexicon Village)

**走進一個你不認識的語言**。村裡的人說 7 種陌生的字，你看著他們的動作慢慢猜，把意義拼回去。30-60 分鐘的解謎散步。

### v1.0 核心特色

- **7 位 NPC 各自演 1 段** — 麵包師、鐵匠、漁夫、織女、小孩、旅人、說書婆婆，每人 3 個字
- **波紋擴散時刻** — 拼對 3 個字後，遠近順序炸開一波光暈，世界瞬間變可讀
- **每次玩語言都不同** — 種子（seed）決定這次的語言長相，可分享 share-code 讓朋友玩同一套字
- **村莊長老的最終問題** — 全字認完後，長老問你一句話。你能不能讀懂，就是這支遊戲的結局

### 玩法簡介

- 滑鼠點 NPC 對話
- N 鍵開筆記本，拖意義圖示對齊外語字
- 拼對整段對話 → cascade 波紋
- 全部 NPC 完成 → 點長老 → 結局

## 技術 highlights

- Godot 4.6
- 487 unit tests + integration tests
- Web build ~12.5 MB（gzipped）
- 純鍵盤 / 滑鼠 / 觸控相容（行動版瀏覽器尚為 beta）
- 中英雙語字型 (jf-openhuninn) + 自繪 8×8 像素古字型

## Known limitations

- Web 音訊需要先點過螢幕一次（瀏覽器 autoplay 限制）
- 行動版觸控目前可玩但 UI 不完全為觸控優化
- 字典村莊的 cascade shimmer 音效在某些 Firefox 版本可能無 spatial pan
